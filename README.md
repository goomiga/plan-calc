# Калькулятор ПЛАН

Расчёт стоимости проектирования. Сейчас реализована стадия «Р»: корпуса (коэффициенты повторяемости), разделы АР/КР/ИОС, генплан (ПЗУ).

Одностраничное приложение без сборки: весь код в `index.html`. Данные хранятся в браузере пользователя.

Планируется: стадия «П» (ПП № 87), концепция.
